# Теория баз данных и MS SQL

Учебные работы за период изучения дисциплины на 3 курсе.

Дисциплина охватывает архитектуру хранения данных, выбор СУБД, проектирование и нормализацию реляционных баз, MS SQL Server и SSMS, программирование на T-SQL, индексы, процедуры, функции и триггеры.

## Навигация по работам

- [01. Карта размещения данных платформы «Курсатор»](works/01-data-placement-map/README.md)
- [02. Основы MS SQL Server и SSMS](works/02-ssms-basics/README.md)
- [03. Электронная библиотека](works/03-electronic-library/README.md)
- [04. Книжный магазин: T-SQL и индексы](works/04-bookstore-tsql/README.md)
- [05. Логика службы каршеринга электромобилей](works/05-electric-car-sharing/README.md)
- [06. Киберспортивная турнирная платформа](works/06-esports-tournament/README.md)

## Структура

- `works/` — отдельная папка каждой работы, README и выполненные файлы.
- `materials/assignments/` — условия преподавателя с теми же номерами.
- `materials/theory/` — учебные презентации.
- [Соответствие исходных файлов](FILE-MAPPING.md).

Номера 01–06 введены для единой навигации, а не как подтверждение исходной нумерации преподавателя. В двух исходных PDF описана одна работа по книжному магазину; обе версии сохранены под номером 04. Ссылка на первую выгрузку и файлы DB-theory относятся к работе 01.

## Использование

PDF открываются в просмотрщике, DOCX — в Word или совместимом редакторе, PPTX — в PowerPoint. Для повторения практики по SQL используются Microsoft SQL Server и SQL Server Management Studio. Отчёты сохранены в исходном виде, включая изображения. SQL-сервер при сборке репозитория не запускался, корректность всех решений отдельно не подтверждалась.

Репозиторий объединяет все файлы из предоставленной папки и файлы первого проекта DB-theory. Полнота относительно всего учебного плана определяется наличием исходных работ.
