# 05. Логика службы каршеринга электромобилей

## Что изучалось

Выбор объектов T-SQL, автоматизация бизнес-правил, транзакции, обработка ошибок и тестовые вызовы.

## Задание

Выбрать и реализовать процедуры, функции и триггеры для аренды электромобилей, смены статусов, рейтинга и зарядки.
