# 04. Книжный магазин: T-SQL и индексы

## Что изучалось

TOP WITH TIES, EXISTS, TRY/CATCH, THROW, OUTPUT, WHILE, MERGE, GO, индексы и анализ планов.

## Задание

Спроектировать книжный магазин в 3NF, подготовить данные и решить задания по T-SQL, индексам и планам выполнения.
