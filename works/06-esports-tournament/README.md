# 06. Киберспортивная турнирная платформа

## Что изучалось

Хранимые процедуры, скалярные и табличные функции, AFTER и INSTEAD OF триггеры, транзакционная целостность.

## Задание

Реализовать 3 процедуры, 3 функции и 3 триггера для регистрации игроков, завершения матчей, призовых, рейтингов и трансферов.
