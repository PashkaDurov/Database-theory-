# 01. Карта размещения данных платформы «Курсатор»

## Что изучалось

Анализ нагрузки, выбор SQL и NoSQL хранилищ, ACID, согласованность данных, проектирование архитектуры хранения.

## Задание

Выбрать хранилища для пользователей, сессий, курсов, прогресса, поиска, форума, логов, аналитики и рекомендаций. Описать источники истины, кэширование, TTL и синхронизацию.
