# 03. Электронная библиотека

## Что изучалось

Нормальные формы 1NF–3NF, первичные и внешние ключи, ограничения целостности и связи между таблицами.

## Задание

Спроектировать LibraryDB для книг, авторов, жанров, читателей и выдач; выполнить нормализацию и реализовать ключи и ограничения в SQL Server.
